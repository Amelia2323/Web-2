3. Jelaskan apa yang dimaksud dengan perintah git : init, clone, remote, add, commit, push
dan checkout
Jawab: - git init untuk membuat repository git 
baru- git clone untuk membuat salinan repository lokal
- git remote repositori umum yang digunakan semua anggota tim untuk bertukar perubahan mereka 
- git add untuk untuk perintah menambahkan file baru ke repository yang baru dipilih
- git commit untuk untuk menyimpan apabila terjadi perubahan dan dilakukan pada repository jarak jauh, namun tidak bisa melakukan perubahan. 
- git push untuk mengunggah file dari local repository ke remote repository
- git checkout untuk melakukan switch branch yang sedang aktif. Selain itu, menggunakan perintah ini, kita juga bisa memulihkan file
